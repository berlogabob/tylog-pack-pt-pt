Opinião: game frameworks

Лексика игровых движков (motor de jogo, biblioteca, desempenho, código aberto, curva de aprendizagem), сравнения mais … do que, tão … como, melhor / pior и спор в духе Unity vs Godot.

Результат урока

  • назвать 20 терминов игровой разработки по-португальски;
  • сравнить два инструмента четырьмя конструкциями сравнения;
  • использовать melhor / pior / maior / mais pequeno без ошибок;
  • отстоять выбор движка: мнение + два аргумента + пример, 3 минуты;
  • написать 100–120 слов сравнения двух инструментов.

Режим: три блока по 30 минут. Связки урока 49 и embora урока 50 — обязательны в речи и тексте.

Сессия 1 — язык и форма 30 минут

1. Диалог

Alex: Sofia, este semestre estou a pensar em mudar do Unity para o Godot nas aulas.

Sofia: A sério? Porquê? O Unity é o motor mais usado na indústria.

Alex: Sim, mas o Godot é código aberto e gratuito. Os alunos não precisam de licença.

Sofia: Concordo, mas o desempenho do Unity é melhor em projetos grandes.

Alex: Para um protótipo de dez semanas, o desempenho não é o problema. A curva de aprendizagem é mais importante.

Sofia: E qual é mais fácil?

Alex: Na minha opinião, o Godot é tão fácil como o Unity, e o editor é mais leve.

Sofia: Tão fácil? O Unity tem mais tutoriais e uma comunidade maior.

Alex: É verdade. Embora a documentação do Godot seja mais curta, é mais clara.

Sofia: Então fazes uma aula com cada motor e os alunos escolhem?

Alex: Boa ideia. Assim comparam as ferramentas e decidem.

Sofia: Para mim, é a melhor solução. Depois conta-me o que escolheram.

  1. Без текста: какие два аргумента за Godot, какие два за Unity, чем всё кончилось?
  2. С текстом: выпишите все сравнения. Их не меньше семи.
  3. Без текста: реплики Alex.

3. Сравнение

КонструкцияЗначениеПример
mais + прил. + do queболее … чемO Unity é mais pesado do que o Godot.
menos + прил. + do queменее … чемO Godot é menos conhecido do que o Unity.
tão + прил. + comoтакой же … какO Godot é tão fácil como o Unity.
tanto(s)/tanta(s) + сущ. + comoстолько же … сколькоNão tem tantos tutoriais como o Unity.
verbo + mais / menos do queглагол + больше / меньшеO Godot pesa menos do que o Unity.
o / a mais + прил.самый …É o motor mais usado na indústria.

Неправильные: bom → melhor, mau → pior, grande → maior, pequeno → mais pequeno. PT-PT говорит mais pequeno; бразильское menor в PT-PT звучит формально. Никогда *mais bom, *mais grande. Наречия: bem → melhor, mal → pior: O Godot exporta melhor para a web.

do que и que оба верны; в PT-PT чаще do que. После tão … como — только como, не *do que.

Упражнение A — постройте сравнение из подсказки

Пример: Unity / pesado / + / Godot → O Unity é mais pesado do que o Godot.

  1. Godot / leve / + / Unity
  2. documentação do Godot / longa / − / documentação do Unity
  3. curva de aprendizagem do Unreal / difícil / = / curva do Unity
  4. comunidade do Unity / grande / + / comunidade do Godot
  5. desempenho do Godot em 3D / bom / − / desempenho do Unity (pior)
  6. editor do Godot / pequeno / + / editor do Unity
  7. Godot / tutoriais / = / Unity (não)
  8. protótipo em 2D / rápido / + / protótipo em 3D
Ответы

1. O Godot é mais leve do que o Unity. 2. A documentação do Godot é menos longa do que a documentação do Unity. 3. A curva de aprendizagem do Unreal é tão difícil como a curva do Unity. 4. A comunidade do Unity é maior do que a comunidade do Godot. 5. O desempenho do Godot em 3D é pior do que o desempenho do Unity. 6. O editor do Godot é mais pequeno do que o editor do Unity. 7. O Godot não tem tantos tutoriais como o Unity. 8. Um protótipo em 2D é mais rápido do que um protótipo em 3D.

Упражнение B — вставьте слово из таблицы лексики
  1. O Godot é ___: qualquer pessoa pode ler e mudar o código.
  2. Os alunos fazem um ___ em dez semanas, não um jogo completo.
  3. Com um computador fraco, o ___ do editor é mau.
  4. A ___ do Unreal é muito difícil para principiantes.
  5. Para usar o Unity numa empresa, é preciso pagar uma ___.
  6. Quando o jogo está pronto, ___ para Windows e para a web.
  7. Não percebo esta função. Vou ler a ___.

Ответы

código aberto; protótipo; desempenho; curva de aprendizagem; licença; exportamos; documentação; erro (bug).

Упражнение C — исправьте ошибку в сравнении
  1. O Unity é mais bom do que o Godot para 3D.
  2. O editor do Godot é menor do que o do Unity.
  3. O Godot é tão leve do que o Unity.
  4. A comunidade do Unity é mais grande.
  5. O Godot tem tanto tutoriais como o Unity.
  6. O Unreal exporta mais bem para consolas.
Ответы

1. mais bom → melhor. 2. menor → mais pequeno (PT-PT). 3. tão leve do que → tão leve como. 4. mais grande → maior. 5. tanto tutoriais → tantos tutoriais. 6. mais bem → melhor.

Упражнение D — мнение о движке: закончите фразу с аргументом
  1. Na minha opinião, o Godot é melhor para principiantes porque …
  2. Para mim, o Unity continua a ser a melhor escolha para …
  3. Embora o Unreal tenha o melhor desempenho, …
  4. Concordo que o código aberto é importante, mas …
  5. Uma biblioteca é mais leve do que um motor, por isso …
  6. Se o computador do aluno é fraco, …
Возможные ответы

1. … é gratuito e o editor é leve. 2. … quem quer trabalhar na indústria. 3. … a curva de aprendizagem é muito difícil para dez semanas. 4. … a comunidade também conta. 5. … é melhor para um jogo pequeno em 2D. 6. … o Godot funciona melhor do que o Unity.

  2. С текстом: слушайте melhor — «мильóр», с мягким lh; pior — «пиóр», один слог после p.
  3. Shadowing реплик Sofia — она задаёт вопросы и возражает: копируйте восходящую интонацию.
  4. Монолог ниже — без текста: какой инструмент выбирает Inês и почему.

Монолог — Inês о выборе инструмента для веб-игры

Inês: Para o projeto da game jam, escolhi uma biblioteca em vez de um motor. Na minha opinião, para um jogo pequeno em 2D no browser, uma biblioteca é mais leve e mais rápida do que o Godot ou o Unity. Não tem editor, é verdade, e a curva de aprendizagem é um pouco maior no início, porque tudo é código. Mas o desempenho na web é melhor e o ficheiro final é muito mais pequeno. Além disso, é código aberto e tem uma documentação tão boa como a dos motores grandes. Embora a minha equipa prefira o Godot, acho que, para quarenta e oito horas, esta é a escolha certa. Se o jogo crescer, mudamos de ferramenta.

Наблюдения PT-PT

  • do que в потоке — «дук»: o редуцируется до «у», конечное e почти исчезает.
  • tão … como: tão носовой, como с редуцированным конечным «у».
  • desempenho — ударение на pe, nh мягкое: «дезэмпéню».
Проверка понимания — монолог
  1. Что выбрала Inês: движок или библиотеку?
  2. Для какого типа игры?
  3. Два минуса библиотеки?
  4. Два плюса?
  5. Что предпочитает её команда?
  6. Сколько длится game jam?
  7. Что будет, если игра вырастет?
Ответы

библиотеку; маленькая 2D-игра в браузере; нет редактора, кривая обучения в начале круче; лучше производительность в вебе, файл намного меньше (плюс открытый код и хорошая документация); Godot; 48 часов; сменят инструмент.

Сессия 3 — речь и письмо 30 минут

1. Подстановочная речь

  • O Godot é mais leve do que o Unity.
  • O Unity tem mais tutoriais do que o Godot.
  • O Godot é tão fácil como o Unity.
  • O desempenho do Unreal é melhor, mas a curva de aprendizagem é pior.
  • Embora o Unity seja mais usado, prefiro o Godot porque é gratuito.
  • Para um protótipo, o melhor é uma biblioteca.

2. Мнение 3 минуты

Тема: «Qual é o melhor motor para principiantes?» Структура: мнение (1 фраза) → аргумент 1 со сравнением → аргумент 2 со сравнением → конкретный пример из ваших занятий → вывод с por isso. Запишите одним дублем, затем посчитайте сравнения (минимум четыре) и связки (минимум четыре).

3. Письмо

100–120 слов: сравните два инструмента, которые вы реально используете (движок, библиотека, редактор, даже DAW для музыки). Обязательно: mais … do que, tão … como, melhor или pior, одно embora, одно por isso.

Опора — открыть только если застряли

Nas minhas aulas uso o Unity e o Godot, e para mim cada um tem o seu lugar. O Unity é mais conhecido e tem uma comunidade maior, por isso os alunos encontram tutoriais para tudo. No entanto, é mais pesado do que o Godot e precisa de licença nas empresas. O Godot é gratuito e de código aberto; o editor é mais leve e a documentação é tão clara como a do Unity, embora seja mais curta. Para 3D, o desempenho do Unity é melhor. Para um protótipo em 2D de dez semanas, o Godot é a melhor escolha, porque os alunos começam a programar no primeiro dia.

  1. Тема «технологии» или «компьютер».
  2. С каждым из 5 слов — фраза со сравнением.
